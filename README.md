# The Autonomous Shift // AI, Agents & Agentic Intelligence

An interactive, editorial presentation website and architectural master dossier exploring the evolution from standalone Large Language Models (LLMs) to goal-directed AI Agents, multi-agent swarms, and governed continual learning.

Synthesized directly from canonical AI research:
- `AI_Agents_Agentic_AI_Overview.pdf`
- `AI_Agents_and_Agentic_AI.pdf`
- Multimedia Walkthrough: `explanation short.mp4`

---

## Key Interactive Features

- **The 5-Layer Iceberg Model:** Visual vector iceberg distinguishing deployed systems (*Above the Waterline*) from research frontiers (*Below the Waterline*), featuring real-time hover telemetry.
- **Executive Video Briefing:** Embedded 1080p Full HD video explanation (`explanation short.mp4`) with chapter navigation and variable playback speed controls.
- **Theme Switcher:** Seamless toggle between **Obsidian Dark** (luxury charcoal obsidian with champagne gold & signal emerald) and **Ivory Luxe Light** (editorial ivory with cognac & deep forest green) — zero generic AI blue gradients.
- **Live Canvas Swarm Simulation:** 60fps message-bus simulation showing an Orchestrator dynamically routing tasks to Research, Analyst, Builder, and Reviewer agents.
- **Next-Token Generation Lab:** Interactive autoregressive sampling simulator with probability logits and context buffer accumulation.
- **3-Level Real-World Scenario:** Comparative breakdown of how a single prompt is handled across standard AI, an AI Agent, and an Agentic Workflow.
- **Epistemology of AI:** Architectural breakdown of knowledge stored *In the Weights*, *In the Context*, and *Outside the Model (RAG)*.
- **Enterprise Guardrails Sandbox:** Interactive security policy tester covering RBAC permissions, cost caps, and human-in-the-loop approval gates.

## Live Deployment & GitHub Pages

This project is self-contained with no external build steps required.

### Local Preview
Double-click `index.html` to open in any modern web browser.

### Publishing on GitHub Pages
1. Navigate to the repository on GitHub: `https://github.com/Praveenkumar-2006/AI-and-its-Evo`
2. Go to **Settings** &rarr; **Pages** (under Code and automation).
3. Under **Build and deployment** &rarr; **Branch**:
   - Select branch: `main`
   - Select folder: `/ (root)`
4. Click **Save**.
5. Your live site will be accessible at:
   `https://praveenkumar-2006.github.io/AI-and-its-Evo/`
